Tab button — underline or button-white, current / hover / focus / disabled, optional badge (240 variants).

Underline tabs switch page sections; button-white tabs sit in a gray 8px tray and switch a data range.

```jsx
<TabButtonBase />
```

Props
- `current` — boolean
- `type` — `button white` | `underline`
- `fullWidth` — `false`
- `badge` — boolean
- `state` — `default` | `focus` | `hover`
