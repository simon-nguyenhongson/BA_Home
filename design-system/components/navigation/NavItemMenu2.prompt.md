A row inside a nav menu — icon, label, optional badge and chevron.

Building block for Menu and NavDropdownSubMenu.

```jsx
<NavItemMenu2 />
```

Props
- `icon` — `no icon` | `icon lead`
- `state` — `default` | `focused` | `hover`
- `breakpoint` — `desktop` | `mobile`
- `linkText` — boolean
- `badge` — boolean
- `subText` — boolean
