Inline notice in four semantic tones (primary, success, warning, danger) and two sizes.

For in-context guidance; use Alert for page-level messages.

```jsx
<Callout />
```

Props
- `color` — `success` | `danger` | `warning` | `primary`
- `size` — `md` | `sm`
- `icon` — boolean
- `hasContent` — boolean
- `button` — boolean
- `description` — boolean
