The bare 16px checkbox box, no label.

Use inside table header and body cells; prefer CheckboxText when there is a label.

```jsx
<Checkbox />
```

Props
- `checked` — boolean
- `indeterminate` — boolean
- `size` — `sm` | `md`
- `type` — `checkbox` | `radio`
- `text` — boolean
- `state` — `default` | `hover` | `focused` | `disabled`
- `supportingText` — boolean
