Switch for settings that take effect immediately — 2 sizes, optional label and description.

Never pair a Toggle with a Save button.

```jsx
<Toggle />
```

Props
- `pressed` — boolean
- `size` — `md` | `sm`
- `text` — boolean
- `state` — `default` | `disabled` | `hover` | `focused`
- `tooltip` — boolean
- `subText` — boolean
