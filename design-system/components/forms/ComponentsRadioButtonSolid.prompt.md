Radio with label, 3 sizes, checked / unchecked / disabled.

Use radio when the choice is confirmed by a separate action; use Toggle when it applies immediately.

```jsx
<ComponentsRadioButtonSolid />
```

Props
- `size` — `sm` | `md` | `lg`
- `position` — `left` | `center` | `right`
- `checked` — boolean
- `disabled` — boolean
- `animation` — `none` | `hovered`
