One day cell inside the calendar grid.

Carries selected, in-range, today and out-of-month treatments.

```jsx
<DateDayItem />
```

Props
- `inView` — boolean
- `today` — boolean
- `selected` — boolean
- `rangeStart` — boolean
- `inRange` — boolean
- `rangeEnd` — boolean
- `hovered` — boolean
- `disabled` — boolean
