Text input sized for in-cell editing.

Used by CellBodyNormal's editable types.

```jsx
<TextField />
```

Props
- `required` — boolean
- `type` — `default` | `no label` | `label tooltip`
- `destructive` — boolean
- `state` — `default` | `hover` | `filled` | `focused` | `disabled`
- `addon` — `default` | `left`
