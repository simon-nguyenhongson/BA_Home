The field shell shared by the in-table inputs.

Compose when you need a cell-height input the cell types do not cover.

```jsx
<InputField />
```

Props
- `label` — boolean
- `textHint` — boolean
- `xIcon` — boolean
- `size` — `sm` | `md`
- `type` — `default` | `tags`
- `destructive` — boolean
- `state` — `placeholder` | `hover` | `filled` | `focused` | `disabled`
- `rightIcon2` — boolean
- `tag` — boolean
- `leadIcon1` — boolean
